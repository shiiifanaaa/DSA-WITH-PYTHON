## Complexity Analysis

| Case | Time Complexity |
|---|---|
| Best Case (Optimized) | O(n) |
| Average Case | O(n²) |
| Worst Case | O(n²) |

Space Complexity: O(1)

## Key Takeaways

- Bubble Sort compares adjacent elements.
- Elements are swapped when they are in the wrong order.
- The largest element moves to the end after each pass.
- The optimized version uses a swapped flag to stop early if no swaps occur.
- Bubble Sort is a stable and in-place sorting algorithm.


# Day 02 - Linear vs Nonlinear Data Structures

## 1. Linear Data Structures

A linear data structure stores elements in a sequential order.

Each element is connected to its previous or next element, except at the ends.

Examples:
1. Array
2. Linked List
3. Stack
4. Queue

## 2. Nonlinear Data Structures

A nonlinear data structure stores elements in a hierarchical or interconnected manner.

Elements are not arranged in a single sequential order.

Examples:
1. Tree
2. Graph

## 3. Linear vs Nonlinear

| Linear | Nonlinear |
|---|---|
| Sequential arrangement | Hierarchical or interconnected |
| Single-level traversal | Multiple possible paths |
| Simpler relationships | More complex relationships |
| Array, Stack, Queue | Tree, Graph |

## 4. Stack

A Stack is a linear data structure that follows LIFO.

LIFO = Last In, First Out.

Example:
A stack of plates. The last plate placed is removed first.

Main operations:
- Push: Insert an element.
- Pop: Remove the top element.
- Peek: View the top element.

## 5. Queue

A Queue is a linear data structure that follows FIFO.

FIFO = First In, First Out.

Example:
People standing in a ticket counter queue.

Main operations:
- Enqueue: Insert an element.
- Dequeue: Remove an element.
- Front: View the first element.

## 7. Key Takeaways

- Linear structures store elements sequentially.
- Nonlinear structures represent hierarchical or interconnected data.
- Stack follows LIFO.
- Queue follows FIFO.

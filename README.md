# DSA with Python

This repository contains my daily learning and practice of **Data Structures and Algorithms (DSA)** using Python.

I am starting with the fundamentals of DSA and gradually building my problem-solving and logical thinking skills through theoretical learning and practical Python programs.

## Topics Covered

- Introduction to Data Structures and Algorithms
- Linear and Nonlinear Data Structures
- Time and Space Complexity
- Big O Notation
- Arrays and Python Lists
- Array Traversal

## Repository Contents

Each day's folder contains:

- `README.md` – Notes, concepts, explanations and examples.
- `practice.py` – Python programs and coding exercises based on the topics learned.

| Case | Time Complexity |
|---|---|
| Best Case | O(n) |
| Average Case | O(n²) |
| Worst Case | O(n²) |

Space Complexity: O(1)

## Key Takeaways

- Insertion Sort builds a sorted portion one element at a time.
- The key stores the element to be inserted.
- Larger elements are shifted to the right.
- The key is inserted into its correct position.
- It performs efficiently on small and nearly sorted datasets.
- It is a stable and in-place sorting algorithm.


# Day 01 - Introduction to DSA

## 1. What is DSA?

DSA stands for Data Structures and Algorithms.

- Data Structures: Ways of organizing and storing data.
- Algorithms: Step-by-step procedures used to solve problems.

## 2. Importance of DSA

- Helps solve problems efficiently.
- Improves logical thinking.
- Reduces execution time.
- Helps manage memory efficiently.
- Important for coding interviews.

## 3. What is a Data Structure?

A data structure is a method of organizing and storing data so that it can be accessed and modified efficiently.

Examples:
- Array
- Linked List
- Stack
- Queue
- Tree
- Graph

## 4. What is an Algorithm?

An algorithm is a finite sequence of steps used to solve a particular problem.

### Example: Adding Two Numbers

Algorithm:
1. Start.
2. Read two numbers A and B.
3. Calculate Sum = A + B.
4. Display Sum.
5. Stop.

Python Program:

a = 10
b = 20
sum = a + b
print(sum)

Output:
30

## 6. Key Takeaways

- DSA combines data structures and algorithms.
- Data structures organize data.
- Algorithms solve problems step by step.

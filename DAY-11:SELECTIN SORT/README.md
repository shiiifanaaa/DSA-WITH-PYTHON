## Complexity Analysis

| Case | Time Complexity |
|---|---|
| Best Case | O(n²) |
| Average Case | O(n²) |
| Worst Case | O(n²) |

Space Complexity: O(1)

## Key Takeaways

- Selection Sort finds the smallest element in the unsorted portion.
- It swaps the smallest element with the first unsorted element.
- It performs at most one swap per pass.
- Its time complexity is O(n²) in all cases.
- Standard Selection Sort is an in-place but unstable sorting algorithm.
